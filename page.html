01 — About

Engineer across the whole stack — silicon to screen

I'm an Electronics & Telecommunication Engineering graduate from CUET working in IoT and R&D. Most engineers pick a layer. I've spent my career refusing to.

My day-to-day sits where physical hardware meets intelligent software: ESP32 firmware streaming biomedical signals over Wi-Fi, YOLO models reading Bangladeshi licence plates off RTSP camera feeds, industrial weighing scales parsed over RS232, and Django/FastAPI services holding it all together behind Docker on a Linux VPS.

That breadth is deliberate. When an ECG stream goes silent, the bug can live in the firmware, the network, the reverse proxy, the API throttle, or the browser — and I'm comfortable tracing it through every one of them. Right now I'm deepening the AI side of that stack: training my own YOLO detectors and OCR models, and expanding into NLP, RAG and agentic systems.

Flagship · Production · @magnetismtech

Industrial ANPR & Gate Monitoring System

Live

An end-to-end computer-vision system for shipping & logistics gates. Vehicles are detected and read from live RTSP feeds, plates are recognised through a Bangla OCR pipeline, and the result is tied to an industrial weighing session — all coordinated by a Python backend and an operator dashboard.

IP Cameras (RTSP)→YOLO vehicle detect→ Plate detect→Character OCR→ Plate reconstruction→Backend + DB→Dashboard
  • 24/7 gate-event cameras with configurable virtual detection line and IN/OUT direction logic
  • Conditional weight-session cameras bound to live scale readings
  • Architected for multi-camera scale — up to 28 concurrent RTSP streams
  • GPU and CPU inference paths for deployment flexibility on edge hardware
  • Python
  • YOLOv8/11/26
  • OpenCV
  • FastAPI
  • RTSP
  • Docker
  • Linux
  • React

Computer Vision · Model training

Bangla Licence Plate OCR

A character-level OCR pipeline for Bangladeshi licence plates — trained from scratch rather than adapted from an off-the-shelf model, because Bangla script has no usable pretrained detector.

  • 4,530 source images augmented to 33,511 training entries (~31% real)
  • 102-class Bangla character map with full class-alignment validation
  • Trained on Tesla T4 — YOLO11s, 100 epochs, PyTorch + CUDA 12.8
  • CVAT annotation workflow and dataset QA
  • YOLOv8
  • YOLO11
  • YOLO26
  • Ultralytics
  • PyTorch
  • CVAT

Healthcare platform · Production

Medical Device Integration Platform

Live

A backend platform connecting ESP32-based medical devices to a clinical EMR in real time. Devices register themselves, open sessions, and stream physiological data that reaches the clinician's browser with sub-second latency.

ESP32 device→WebSocket / HTTP→ Django + DRF→Stream processor→ SSE→Browser→Laravel EMR
  • Device registry, auto-registration and session lifecycle management
  • WebSocket ingestion via Daphne behind an Apache mod_proxy_wstunnel reverse proxy
  • Server-Sent Events fan-out for live in-browser waveform rendering
  • Dockerised deployment: GitHub Actions → GHCR → Linux VPS, with PostgreSQL and Redis
  • Diagnosed a silent-stream bug down through firmware timing → 240 req/min → a 120 req/min DRF throttle

Embedded · Biomedical

ESP32 ECG Acquisition Device

A connected ECG front-end built on the MAX30003 analog AFE, streaming clinical-grade waveform data off an ESP32 over Wi-Fi.

  • 256 Hz continuous sampling with millivolt-calibrated output
  • Custom binary packet protocol — 64 samples per POST, ~4 posts/second
  • First-boot AP-mode provisioning with credentials persisted to NVS
  • Automatic reconnection and heartbeat/keepalive handling
